FROM BROWSER TO BROADCAST

On your stream in 60 seconds.

No plugins. No installation. Just a Browser Source.

  1. 01

    Make your link

    Enter your Twitch channel above, choose your settings, and click Copy OBS URL.

  2. 02

    Add to OBS

    Add a Browser Source, paste the URL, and set the size to 1920 × 1080. The live overlay is transparent.

  3. 03

    Give chat the stage

    Check Control audio via OBS and adjust the source in your mixer. Allow the first model download to finish. If prompted, right-click → Interact → Start audio.

Keep “Shutdown source when not visible” off to keep chat connected. Browser preview audio and OBS audio are separate: close or mute the preview when broadcasting.

Built with OpenAI Codex. Local TTS: piper-plus (MIT) and ONNX Runtime Web (MIT). All character artwork is original SVG created for ChatStage.

CSS10 voice credit: CSS10 Japanese model by ayousanz, based on CSS10 by Kyubyong Park and Thomas Mulc; Japanese reader: ekzemplaro, Meian by Natsume Sōseki. Model card: CSS10 public-domain dataset terms. The CSS10 repository code uses Apache-2.0; LibriVox recordings are public domain in the USA, with local copyright status to be checked elsewhere. Piper TTS: rhasspy; MB-iSTFT-VITS: Kawamura et al.

*Language note: The pinned runtime has G2P support for en / ja / zh / ko / es / fr / pt / sv. The CSS10 voice model contains only en / ja / zh / es / fr / pt language IDs. Korean and Swedish are detected and preferences are saved, but their speech is skipped with an explicit notice until compatible models are available. Caption highlighting estimates text position from phoneme timing; it is not word alignment.

Privacy: Twitch sends chat directly to this browser. Speech is generated here. CDNs and Hugging Face receive asset-download requests and normal connection metadata, never chat text from ChatStage. No analytics, cloud TTS, or message logging. Preferences use localStorage; model downloads use IndexedDB. Browser/OBS storage is separate and the first run needs internet access.
